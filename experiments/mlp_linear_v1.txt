# The winning setting is the starting point for adding hidden layers.
#
# Grid (36 configurations x 3 seeds = 108 runs), everything else at the
# models/mlp.py defaults (all fit rows, last 15 days held out for early
# stopping, patience 3):
#   learning rate   1e-4, 3e-4, 1e-3     (current MLP: 1e-3, training unstable)
#   weight decay    0, 1e-5, 1e-4        (plays the role of ridge's lambda)
#   batch size      4096, 16384          (bigger = smoother updates)
#   input clipping  +-5 sigma, off       (ridge sees unclipped inputs; "off" = 1e6)
#   max_epochs 30 (from 20): small learning rates may need more passes.

# intercept, standardized inputs, and early stopping instead of a fixed lambda.
